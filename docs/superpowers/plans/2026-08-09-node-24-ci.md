# Node 20→24 en el CI de miniapps (#15) — Plan

> REQUIRED SUB-SKILL: superpowers:executing-plans. Cambio de mantenimiento (version bump), verificado por CI.

**Goal:** Bumpear `node-version: 20 → 24` en los 4 workflows que quedan en 20 (template ×3 + host tests.yml). El resto (host-compat, host-contract, backstage-web) ya está en 24.

## Global Constraints

- Solo cambia `node-version`. Nada de lógica.
- `miniapp-template/main` y `backstagereactnative/main` protegidos → entran por **PR** (checks verifican el bump en 24).
- Riesgo real acotado: **jest-RN en node 24** (host `tests.yml`) — el check `test` del PR lo confirma.

---

### Task 1: Template (3 workflows → Node 24)

**Files:** `miniapp-template/.github/workflows/{check-compat,publish,tests}.yml`

- [ ] **Step 1** Cambiar `node-version: 20` → `24` en los tres.
- [ ] **Step 2** Branch + PR a `miniapp-template`. El check `test` corre `node --test` + tsc en node 24 → debe pasar.
- [ ] **Step 3** Merge.
- [ ] **Step 4** Verificar los reusables en 24: disparar un run de compat/publish de una miniapp (ej. re-trigger del demo PR #5, o `gh workflow run ci.yml` en hellow_widget) → check-compat/publish corren en node 24 verdes.

---

### Task 2: Host (`tests.yml` → Node 24)

**Files:** `backstagereactnative/.github/workflows/tests.yml`

- [ ] **Step 1** `node-version: 20` → `24`.
- [ ] **Step 2** Branch + PR a `backstagereactnative`. El check `test` corre **jest (RN)** + node:test + tsc en node 24 → **la verificación clave**. Si jest-RN falla en 24 → investigar (posible incompat jest 29 / babel-preset con node 24) antes de mergear.
- [ ] **Step 3** Merge.

---

## Notas
- Si jest-RN rompe en 24 (Task 2): revertir ese archivo a 20 y dejar el host tests.yml en 20 (documentar), sin bloquear el bump del template. El template no corre jest-RN → su bump es seguro igual.
