# Métricas (#12) — Plan

> REQUIRED SUB-SKILL: superpowers:executing-plans. Código en el spec `2026-08-09-metrics-design.md`.

**Goal:** Telemetría de mounts/fallbacks: host reporta → KV counters → dashboard `/metrics`.

## Global Constraints

- **Best-effort en ambos lados** — las métricas NUNCA rompen la app ni el publish (fetch fire-and-forget que no tira; ingest siempre 200).
- Backend en **backstage-web** (vitest, push directo a main → Vercel). Host en **backstagereactnative** (jest, main protegido → PR).
- MVP: contadores `metrics:mount:{id}` + `metrics:fallback:{reason}`. Ingest público + validación por-registry (id debe existir, batch ≤ 50).
